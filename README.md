# Переводчик для игр

Программа для Windows 10/11: переводит английский текст прямо поверх игры и помогает писать по-английски в игровом чате. Работает в фоне, управляется горячими клавишами, значок у часов.

## Скачать

**[Скачать Переводчик (zip, 21 МБ)](https://github.com/aboba-hash/GameTranslator/releases/latest/download/Perevodchik.zip)** · [все версии](https://github.com/aboba-hash/GameTranslator/releases)

Распакуйте архив в любую папку и запустите `Переводчик.bat`. Устанавливать ничего не нужно.

Внутри архива — официальный встраиваемый Python с [python.org](https://www.python.org/downloads/windows/) (файлы `python.exe`, `pythonw.exe`, `python311.dll` подписаны Python Software Foundation — это можно проверить: правой кнопкой → Свойства → Цифровые подписи), библиотеки из `requirements.txt` и сама программа `app/translator.py` открытым текстом. Самодельных `.exe` в архиве нет.

## Это безопасно?

Да. Весь код открыт в этом репозитории. Что программа делает и чего не делает:

- **В интернет** отправляет только текст для перевода — в Google Переводчик, Яндекс Переводчик и (если вы подключили свой ключ) нейросеть Groq. Снимки экрана никуда не отправляются, распознавание текста идёт встроенным в Windows распознавателем.
- **На диск** пишет только в свою папку: настройки, кэш переводов, скриншоты и отчёты, которые вы сами сохранили.
- **В реестр** — только автозапуск, и только если вы включили галочку «Запускать вместе с Windows».
- **Клавиатуру** перехватывает только пока открыта плашка F9 (чтобы набранный текст не уходил в игру), и ничего никуда не записывает и не отправляет.

### Почему раньше антивирус писал «троян»

Первая версия (1.0) собиралась в `Переводчик.exe` с помощью PyInstaller. Windows Defender определял его как `Trojan:Win32/Bearfoos.A!ml`, а на VirusTotal его отметили 4 антивируса из 70 ([отчёт](https://www.virustotal.com/gui/file/58df324619eaa75c2edbab1c53ca14648d108a3fe3de6813096b9b6cc0de7daa)):

| Антивирус | Что написал |
|---|---|
| CrowdStrike Falcon | «вредоносный с уверенностью 70%» |
| Arctic Wolf | «Unsafe» |
| SecureAge | «Malicious» |
| Skyhigh | «BehavesLike.Win64.Backdoor» |

Это **ложные срабатывания**: все четыре — эвристики и машинное обучение («похоже на…»), а не найденный вирус. Антивирусы, которые ищут известные вирусы по базам, — Microsoft, Kaspersky, ESET, Dr.Web, BitDefender, Avast, Malwarebytes и ещё 59 — файл не отметили. Пустая программа «привет», собранная тем же PyInstaller, получила 2 из тех же 4 пометок ([отчёт](https://www.virustotal.com/gui/file/fd477c9817d53cd5a1a0f5290e2f8675347af0fc57d7794b67f2a4a9b08c330b)) — то есть эвристики реагируют на сам упаковщик, а оставшиеся две — на то, что программа снимает экран и работает с клавиатурой (как и положено переводчику для игр).

Чтобы таких пометок не было совсем, с версии 1.1 программа поставляется без самодельного `.exe` — подписанный Python + открытый код.

## Что умеет

| Клавиша | Что делает |
|---|---|
| **F8** | Переводит весь экран. Перевод лежит поверх английского текста и обновляется сам. F8 ещё раз — выключить |
| **F7** | Обвести мышкой область — на её месте появится перевод. Можно скопировать картинкой или текстом, сохранить |
| **Shift+F7** | Перевод чата: один раз обвести окно чата, дальше переводятся только новые сообщения. Shift+F7 — пауза |
| **Ctrl+F7** | Выбрать область чата заново |
| **F9** | Написать по-английски: выделите русский текст → F9, он заменится английским. В игре появится плашка: пишете по-русски, Enter — английский текст впечатывается в чат |
| **Shift+F9** | То же, но без сленга (или со сленгом — зависит от настройки) |
| **Ctrl+F8** | Выход |

Клавиши, прозрачность и размер перевода, автозапуск с Windows — в меню значка у часов → «Настройки…».

## Перевод по смыслу (нейросеть)

Без настройки программа переводит через Google/Яндекс. Если подключить бесплатную нейросеть Groq, F9, F7 и чат переводятся по смыслу: со сленгом, матом той же силы и пониманием контекста («мб сольемся? все равно не вывезем» → «maybe we should bail? we ain't gonna pull it off»).

1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/keys) и создайте ключ (бесплатно).
2. Значок у часов → «Настройки…» → поле «Ключ нейросети Groq» → вставьте ключ (строка вида `gsk_...`) → «Сохранить».

**У каждого должен быть свой ключ**: в программу ключ не встроен, а бесплатный лимит у ключа общий на всех, кто им пользуется. Ключ хранится только у вас — в файле `app/ключ_groq.txt`.

Когда бесплатный лимит заканчивается, программа сама переходит на обычный переводчик и сообщает об этом.

## Требования

- Windows 10 или 11 с установленным **английским языком** (Параметры → Время и язык → Язык) — из него берётся распознавание текста.
- Игра в режиме **«Оконный без рамки»** (Borderless): поверх эксклюзивного полноэкранного режима Windows ничего не рисует.
- Если игра запущена от администратора — меню значка → «Перезапустить от имени администратора».

## Запуск из исходников

```
pip install -r requirements.txt
python translator.py
```

`Собрать портативную.bat` собирает папку и архив, как в релизе. `Проверка.bat` — самопроверка всех функций. Подробное устройство программы — в [ОПИСАНИЕ.txt](ОПИСАНИЕ.txt).

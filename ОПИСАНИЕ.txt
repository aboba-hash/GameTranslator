ПЕРЕВОДЧИК ДЛЯ ИГР — краткое описание проекта
==============================================

Что это
-------
Программа для Windows 10/11, которая переводит английский текст прямо на экране
(в играх, браузере, программах) и помогает писать по-английски в игровых чатах.
Работает в фоне, управляется горячими клавишами.

Клавиши
-------
  F8        - перевод всего экрана (монитор, где мышка). Перевод лежит поверх
              английского текста и сам обновляется, когда экран меняется.
              F8 ещё раз - выключить.
  F7        - обвести мышкой область - на её месте появится перевод картинкой.
              Кнопки: Копировать (картинку), Текст (перевод текстом), Сохранить
              (в папку "скрины"), Оригинал/Перевод, закрыть (Esc / F7).
  Shift+F7  - перевод чата: первый раз обвести окно чата (область запоминается), дальше
              переводятся только новые сообщения, нейросетью. Shift+F7 ещё раз - пауза
              (ничего не распознаётся и не тратит лимит), снова Shift+F7 - та же область.
  Ctrl+F7   - выбрать область чата заново.
              Поверх игры ничего не висит постоянно: строка состояния видна 3 сек после
              изменения, перевод чата прячется через 10 сек без новых сообщений
              (в настройках: 5/10/30 сек или "никогда"), новое сообщение - снова виден.
  F9        - русский -> английский, разговорный, со сленгом (gonna, idk, thx, gg...).
  Shift+F9  - то же, но обычный правильный английский.
              * в программах: выделить русский текст -> F9 -> он заменится английским;
              * в играх (окно на весь экран) или если ничего не выделено: появится
                плашка, печатаете по-русски (буквы НЕ попадают в игру), под ней
                виден перевод; Enter - английский текст впечатывается в чат игры.
                Shift+Enter - без сленга, Tab - раскладка RU/EN, Esc - отмена.
                Ctrl+C - перевод копируется в буфер обмена (вставить Ctrl+V куда угодно).
  Shift+F8  - отчёт в папку "отчёты": снимок экрана + какие строки перевелись,
              какие нет и почему (для поиска ошибок).
  Ctrl+F8   - выход.

Значок у часов (трей): перевести экран/область, настройки - переводить нейросетью (вкл/выкл),
сленг в F9 (вкл/выкл; Shift+F9 всегда наоборот), папки со скринами и отчётами, клавиши, выход.
Настройки запоминаются в "настройки.json" рядом с программой.
Окно "Настройки…" (в меню значка): сменить клавиши (Shift/Ctrl-варианты меняются вместе с основной),
непрозрачность и размер текста перевода поверх игры, нейросеть, сленг, автозапуск с Windows.
Автозапуск пишется в реестр: HKCU\Software\Microsoft\Windows\CurrentVersion\Run, значение GameTranslator.

Окна переводчика каждые полсекунды снова поднимаются наверх - их не перекрывают игры без рамки,
оверлеи Discord/Steam и панель задач. Если игра запущена от администратора: меню значка ->
"Перезапустить от имени администратора" (иначе F9 не сможет печатать в игру).
Если в игре нет режима "Оконный без рамки": поставьте в игре "Оконный", потом значок у часов ->
"Сделать окно игры без рамки" (растянет окно на весь экран без рамки; повторно - вернёт как было).
Если игра в эксклюзивном полноэкранном режиме, при F8/F7/Shift+F7 звучит сигнал, а после выхода
из игры видна подсказка.
Игра должна быть в режиме "Оконный без рамки" (Borderless) - поверх эксклюзивного
полноэкранного режима Windows ничего не рисует. Если игра запущена от администратора,
переводчик тоже нужно запускать от администратора.

Файлы
-----
  translator.py              - ВСЯ программа (один файл, Python 3.14)
  Запустить переводчик.bat   - запуск из исходника (нужен Python + библиотеки)
  Установить библиотеки.bat  - установить библиотеки (один раз на новом ПК)
  Собрать портативную.bat    - собрать папку "Переводчик" (официальный Python с python.org + библиотеки +
                               translator.py) и архив Perevodchik.zip. Запуск - Переводчик.bat.
                               Без самодельного .exe: его (PyInstaller) антивирусы ложно считают трояном
  requirements.txt           - список библиотек с версиями
  icon.ico, make_icon.py     - значок программы и скрипт, который его рисует
  Проверка.bat / проверка.py - самопроверка: библиотеки, распознавание, Google/Яндекс, нейросеть,
                             переход при лимите, мат, F9 в Блокноте (--быстро - без Блокнота)
  кэш_переводов.json         - запомненные переводы (можно удалить - создастся заново)
  error.log                  - появляется только если программа упала (текст ошибки)

Как продолжить работу на другом ПК
----------------------------------
1. Установить Python 3 (python.org), при установке отметить "Add python.exe to PATH".
2. Запустить "Установить библиотеки.bat".
3. Править translator.py (удобно в VS Code), запускать "Запустить переводчик.bat".
   Чтобы видеть ошибки, можно запустить в консоли:  python translator.py
4. Версия, которой не нужен установленный Python - "Собрать портативную.bat".
5. В Windows должен быть установлен английский язык (Параметры -> Время и язык ->
   Язык): распознавание текста берётся из Windows.

Как устроено (по разделам translator.py)
---------------------------------------
  настройки        - вверху файла: клавиши, языки, цвета, частота обновления,
                     UPSCALE (увеличение снимка перед распознаванием) и т.д.
  горячие клавиши  - RegisterHotKey в отдельном потоке -> очередь events -> App.handle
  снимок экрана    - mss; окна переводчика спрятаны от снимков (SetWindowDisplayAffinity),
                     поэтому программа не распознаёт свой же перевод
  распознавание    - встроенный OCR Windows (winrt), 4 прохода одновременно:
                     обычный, "только светлый текст", "только тёмный текст" (для надписей
                     на картинках) + русский (чтобы не переводить уже русский текст).
                     Дальше: отсев мусора, склейка кусков строки, сборка абзацев.
  сленг (EN->RU)   - SLANG_WORDS / SLANG_PHRASES: u, idk, gg, brb... -> нормальный английский
  нейросеть        - F9 и F7 переводит Groq (модель openai/gpt-oss-120b, бесплатно) - по смыслу,
                     с контекстом, сленгом и матом; F7 ещё и исправляет ошибки распознавания.
                     Ключ у каждого свой: вводится в Настройках, хранится в ключ_groq.txt рядом с
                     translator.py (или GROQ_API_KEY в окружении). Без ключа - Google. Лимит кончился (ошибка 429) / нет связи / плохой ключ -
                     нейросеть сама отключается (на время из ответа Groq, 2 мин или до перезапуска),
                     всплывает сообщение, переводит Google. Выключить совсем: AI_TRANSLATE = False.
                     Весь экран (F8) всегда через Google - он обновляется каждую секунду.
  перевод          - Google (translate.googleapis.com, бесплатный); если Google не пускает
                     ("необычный трафик", ошибка 302) - автоматически Яндекс на 10 минут.
                     Открытое соединение + кэш на диске = быстро.
  мат (RU->EN)     - RU_MAT: русский мат заменяется английским с тем же смыслом
                     ("пиздато" -> fucking awesome, "иди нахуй" -> go fuck yourself)
  F9 (RU->EN)      - RU_SLANG (щас, пж, хз, катка, хильни...) -> понятный переводчику текст;
                     EN_CASUAL - делает английский разговорным; исправление опечаток
                     (Google qca или Яндекс.Спеллер)
  буфер обмена     - F9 в программах: Ctrl+C -> перевод -> Ctrl+V, буфер потом возвращается
  F9 в играх       - KeyCapture: перехват клавиатуры (WH_KEYBOARD_LL), пока открыта плашка;
                     type_text: впечатывание через SendInput (скан-коды + английская раскладка)
  App (окна)       - tkinter: прозрачное окно поверх экрана, через которое проходят клики;
                     перевод рисуется полосками ровно по строкам оригинала, цвет фона и
                     букв берётся с экрана

Что проверено и что нет
-----------------------
  Проверено: перевод экрана (F8), области (F7), сленг в обе стороны, запасной Яндекс,
  .exe на этом ПК, обработка клавиш в плашке F9.
  НЕ проверено в настоящей игре: плашка F9 и впечатывание текста в игровой чат.
  F9 в обычных программах (выделить -> заменить) в Блокноте срабатывал не каждый раз.
  Причина найдена (2026-10-07): после нажатия Alt фокус в Блокноте Windows 11 уходит в меню,
  и Ctrl+C туда не доходит. Исправлено: если Ctrl+C не сработал, текст копируется и вставляется
  напрямую в поле ввода (WM_COPY/WM_PASTE), затем ещё одна попытка Ctrl+C; F9 не запускается
  дважды одновременно; развёрнутое окно с заголовком больше не принимается за игру.
  Проверено автотестом в Блокноте: 30/30 обычный случай, 20/20 с нажатым Alt.

Известные ограничения и идеи
----------------------------
  - Мелкий текст (меньше ~12 пикселей) и сильно стилизованные шрифты распознаются плохо.
  - Перевод всего экрана ~1 сек на слабом ноутбуке; область (F7) ~0.5 сек.
  - Google иногда временно блокирует частые запросы - тогда работает Яндекс
    (английский->русский у Яндекса чуть хуже).
  - Раньше программа собиралась в .exe (PyInstaller) - Windows Defender ложно определял его как
    Trojan:Win32/Bearfoos.A!ml, VirusTotal: 4/70 (только эвристики). Поэтому теперь портативная версия:
    подписанный pythonw.exe с python.org + открытый translator.py.
  - Идеи: свои слова в словари сленга,
    другие языки (SOURCE_LANG / TARGET_LANG вверху translator.py).
